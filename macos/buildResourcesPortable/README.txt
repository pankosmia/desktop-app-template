%%APP_NAME%%
MacOS %%ARCH%% Portable App

Place all contents of this directory and any subdirectories on any exFAT-formatted drive.

Run by double-clicking %%APP_NAME%% in a file browser.

Alternative run from a terminal with `./start.sh`.
______________________________________________________

If you get a message saying "Not Opened", then:
    a. Click either "Done" or "Cancel", depending on which of those options you have.
    b. Go to Apple menu > System Preference >  Privacy and Security > General > and at the bottom, where it shows the file that was blocked, click "Allow Anyway" .
    c. Wait until the "___ was blocked" message disappears from the settings page.
If you get "can't open the file" or something else similar, then:
    * Was 'Move to Trash' selected on %%APP_NAME%% on a prior attempt to run? If so, then find it in your trash and 'put back'.
    * Did you place this portable app on your Desktop? If so, look under Settings > Privacy and Security > Files & Folders > Terminal, and see if you need to turn on permissions for Desktop, OR, move your portable app folder to another location and run %%APP_NAME%% from there.
