%%APP_NAME%%
Windows %%ARCH%% Portable App

Place all contents of this directory and all subdirectories on any NTFS-formatted drive. NTFS is necessary for this Windows App to be able to save any edits that you make.

Run by double-clicking the file "%%APP_NAME%%" in Windows Explorer (not the folder but the file).

The file extension connected to the "%%APP_NAME%%" file is ".bat".  It is a "Batch file" that is used to launch this portable app.
